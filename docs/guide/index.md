# 0.1.0a0 文档

这是当前源码开发快照的使用指南，尚未在 PyPI 发布。文档和 SDK 版本均为 `0.1.0a0`；不同提交仍可能包含开发变更，构建清单同时记录精确源码提交与文件校验和。

1. [快速入门](quickstart.md)：从源码安装，运行无 Key 的完整 Agent。
2. [运行原理](concepts.md)：理解 Agent、Runtime、身份、持久化和恢复。
3. [三个参考应用](examples.md)：运行真实本地工具、跨进程 Memory 和审批示例。
4. [Python API](api.md)：查阅已实现入口、字段与 HTTP schema。
5. [模型与 MCP](integrations.md)、[服务与工作台](server.md)、[Docker 与可选 E2B](sandbox.md)：按需连接能力。
6. [数据维护](maintenance.md)、[排错](troubleshooting.md)和[实际支持范围](limits.md)：保存数据并理解限制。

项目内部的规划、行为契约和验证报告仍保存在原位置；本指南引用它们，不另行定义状态机或默认限额。[当前进度](../planning/progress.md)是任务状态的唯一维护位置。
