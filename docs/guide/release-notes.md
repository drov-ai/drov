# 版本说明

## 0.1.0a0 · 源码开发快照

当前没有 PyPI/TestPyPI 发布或已上线官网。以下为实际源码能力摘要，具体任务状态统一见 [progress](../planning/progress.md)；不是另一个发布承诺清单。

现有 SDK 提供类型化 Agent、事务存储、权限工具、上下文来源、显式 Memory、持久人工输入/审批、未知效果核查和恢复。HTTP/SSE 与实验性工作台共用 Runtime。Docker 支持单次 Python、受控文件输入与销毁后持久 CSV/PNG；E2B 是单列可选后端。离线维护包含预览/逻辑清理、显式字节回收/中断台账、abandonment、一致备份/恢复屏障、历史兼容字段迁移和授权副本导出。

### 验证与已知失败

T-16 的固定配置经过真实 smoke7/7 后执行全部81个正式试验，78通过；schema73/75、代码9/9，零安全断言失败。三项失败为一次重复检索和两次输出未遵最终 schema。没有剔除、补抽或把离线夹具混入分数；它只说明该配置达到既定工作门槛。[原报告及复核](../validation/t16-evidence-scope.md)保留准确配置、提交与限制。

最终 T-16 核心11/Docker4 CI jobs 在测试提交 `0aa0168572f7994326e84ab66e53a0a83fae6132` 通过。新的文档构建有自己的验证记录，不用历史 SDK CI 冒充新变更通过。OpenAI 真实模型未跑，使用体验仅维护者验证；无竞品优势结论。

### 兼容与升级

开发快照 API 仍可能变化。存储记录按独立扩展版本校验，旧 SDK 遇到新扩展拒绝；升级/迁移前完整备份，降级不能直接覆盖原库。恢复副本受 recovery barrier 保护，目前没有通用自动/force 解除接口。未知外部效果、活动租约与原费用不因清理或放弃消失。

### 文档版本对应

本地站点在 `/0.1.0a0/` 提供本快照文档，`build-manifest.json` 记录包版本、源码提交、是否存在未提交修改以及输入 hash。初次公开前 T-18 需冻结候选提交/Tag、构件与文档的对应关系；新版本保留原版本快照，不用重建结果覆盖已发布版本的旧字节。当前只有一个开发版本，不展示虚构的历史发行版。
