## 审查方式

沿三个参考场景，从输入、工具、暂停/恢复到结果和资源关闭，交叉检查 API、Runtime、事务/历史、权限、上下文、验收和任务。再检查旧备份恢复、内容清理和正文访问这些跨场景路径。外部证据沿用 2026-10-12 查阅的 [证据记录](evidence.md)，本轮没有新增竞品性能或能力结论。

结构检查覆盖本地链接、编号、说明片段语法、任务依赖及覆盖关系；这是文档验证，不是执行 SDK、数据库或模型。当前没有以竞品实测证明差异化优势。

2026-10-13 最终检查结果：22 份 Markdown、159 个本地链接、10 段 Python 片段语法通过；18 项任务的 23 条依赖与图一致且无环，C/S/X/B 映射完整。以 SHA-256 对照本轮开始时的素材快照，55 个品牌文件未变。检查方法为逐项文件/编号解析、Python 语法编译、依赖图遍历及内容摘要比较；未执行片段或安装 SDK。

## 发现与关闭结果

| 发现 | 已确定的修正 | 规范位置 / 后续验证 |
| --- | --- | --- |
| Memory 示例字段不匹配且只查第一页 | payload 改为 data，逐页确认 memory.changed；工具示例同时传递 tenant/user | [参考应用](reference-scenarios.md)，T-08/T-09 |

| 已消费响应过期后重复请求可能失败 | 当前授权后先查原回执；只对新响应应用有效性检查 | 运行契约第 5 节，B-04 |
| 旧暂停事件会截断重连流，游标定义混用 | 追平当前静止状态才结束；事件 run_id:seq 与列表游标分开，索引按页有界 | [API](api-draft.md)、运行契约第 3 节，B-11 |
| view_content 未覆盖全部入口 | 默认元数据投影，正文权限预检与发送时检查；respond 不隐式读结果 | API、运行契约第 6 节，B-10 |
| 失败/取消后的历史及用量不完整 | 按稳定 ID 记录完整消息组；未派发/未知事实明确；所有 outcome 带 usage | 运行契约第 7/9 节、API，B-03/15 |
| 零重试被误拒绝、非 JSON 转换说法冲突 | 重试允许 0，严格类型子集不隐式转 datetime，其他正限额规则一致 | API、[工程方案](engineering.md)，T-02 |
| 限额耗尽后无法核查；暂停被误写成资源已释放 | 停止 Agent 工作，保留核查；verify 只获取建议，不消费请求；旧调用继续占资源 | 运行契约第 4/9 节、[架构](architecture.md)，B-05/12 |
| 核查 applied 无结果时取消无法收尾，核查过期入口不清 | 取消/限额收尾允许仅提交充分效果证据；核查期限仅提醒 | API、运行契约第 4/5 节，T-09/T-10 |
| 示例首次交付太晚，正文授权责任落到发布任务 | T-06/T-08/T-09 逐步交付离线示例和权限；T-16 汇总评测 | [实施任务](implementation-plan.md)，任务依赖无新增循环 |
| schema 分母混入预期失败，smoke 预算边界模糊 | 预注册 N_struct；任务按 72 项评分；6 smoke 加 72 正式合计 78 项，共用预算 | [质量计划](quality-plan.md)，T-16 |
| extras 与静态资产归属易误读 | extras 选择依赖；T-14 后统一 wheel 带静态资产，SDK 导入不加载服务依赖 | 工程方案，T-01/T-14/T-18 |
