## 已确认方向

Drov 是 Python 通用 Agent 框架，能力范围对标 AgentScope 2.0；渐进 API、统一运行机制、可检查上下文与记忆是待验证的优势假设。三个参考应用检验通用性，不限定业务。类型/schema 通过不代表运行能力或体验领先。

## 下一轮建议：T-03 存储与原子边界

前置 T-02 已完成；任务验收以 [实施计划](implementation-plan.md) 的 T-03 卡为准。本会话继续 T-03。

1. 从归属/记录定义开始，实现内存与 SQLite 存储，所有查询限定 tenant/user/session/agent；为状态、检查点、事件、工具意图与响应保留同事务接点。
2. 实现会话唯一约束、state_version CAS、request_key 去重/冲突及 schema/迁移元数据；去重先于会话忙和容量检查。
3. 验证真实 SQLite 文件与两个独立进程的排他锁、同路径/软链接所有权；事务全成或全败，提交期间取消不释放不明所有权。
4. 完成归属隔离、事务/CAS/去重及锁/故障证据后再关闭整项；若分多轮，记录已验收子范围和具体剩余项。无需模型 Key。

完成 T-03 后下一项为 T-04 注册与资源所有权；不能跳过存储原子边界。
