# ADR-0032：授权分页导出与脱敏副本

日期：2026-10-16（Asia/Shanghai）。T-15工作决定；状态/验证见[progress](../planning/progress.md)/[记录](../validation/t15-migration-export.md)。

## 原因与决定

原始数据库备份含恢复信息和所有作用域，不能用作用户导出。Runtime.export_run复用现有Run/上下文与每个Artifact的当前授权投影，默认元数据；include_content=True另需read/view_content。返回RunExport：原RunInspection事件页/游标、显式正文上下文、显式选定的ExportedArtifact。原RunInspection继续只嵌入上下文摘要，完整上下文放导出的独立字段，不修改原查询协议。

artifact_ids最多16个、不重复，必须属于目标Run的输入或原输出；每个文件分别read/view_content/实际hash读取。没有显式内容选择不导出文件。每份副本包含逻辑名、原ArtifactRef与独立副本size/hash/Base64；应用改写文件时保留原来源hash，另校验导出字节hash。所有读取与脱敏之后再检查当前Run及选定文件权限，撤权失败不返回部分文档。跨tenant和不可见/删除历史遵循现有404/Gone/cursor规则。查看和导出可在恢复屏障下使用，不派发模型、工具或容器。

每页复用原limit/after/has_more，默认100、最高原Runtime上限且不超过500事件；不同页可能观察后续提交，不称全库一致快照。默认最大16MiB，调用方可显式设1字节至64MiB，文件大小在读取前尽量拒绝超限，最终编码前后均检查。不存在默认外部exporter、后台传送、HTTP管理/导出路由或自动写入宿主路径；调用者自行安全保存JSON/文件副本。

导出保留原来源/版本/用量的含义，投影后的正文不作为模型输入的字节重放证明。移除事件中的框架执行/后端控制字段与SandboxResult执行键，对已知执行标识的文本引用做副本投影；被截断JSON预览仅保留原来源/摘要标记，text清空并标export_omitted，避免把片段当完整可投影结果。原私有lease/artifact记录形状拒绝导出，原provider协议内容不展示；常规业务字段如directory保持业务含义，不按名称任意擦除。已授权业务文本/附件可能含应用自行写入的信息，通用框架不保证识别任意业务秘密；源策略的宿主数据边界继续适用。

可选ExportRedactor是宿主提供的纯、非阻塞JSON副本转换：可改正文/逻辑名、去掉附件或显式重算脱敏附件hash，不改存储；禁止改Run/状态/事件页身份、游标/权限标记或引入未选择的来源。异常返回无原文的结构化失败，脱敏后再验证大小、字节hash与权限。redacted只表示应用转换已应用，不宣称任意敏感信息均已识别。原记录/事件/上下文、SDK模型恢复数据和原字节保持；既有下载发现真实损坏时，仍按原规则记录unavailable并失败，脱敏不能修复或改写恢复事实。

## 替代方案与代价

不导出原SQLite/lease/协议条目给普通用户，不默认打包全部文件，不通过脱敏修改运行记录。选择现有授权观察和有界分页，代价是重复授权/文件校验、显式分页与源hash/副本hash区分，以及宿主需要提供业务脱敏函数。恢复整体屏障的核实/解除仍为独立责任。

## 验证

SDK/stream、内存/SQLite、默认元数据/正文上下文、同tenant委托read与view_content分离、跨tenant/撤权/脱敏期间撤权、逐文件权限/归属与未选择来源拒绝、原文/原字节不变、业务字段保留、hash/限额/分页/未知事件/Gone；原来源清理与恢复屏障后共享文件仍可授权导出；实际Docker三入口CSV/PNG与控制字段投影分别验证。具体通过/失败与尚未验收范围只见记录。
