# ADR-0037：Memory 评测的结束规则

日期：2026-10-17。状态：已采纳；真实结果以 [progress](../planning/progress.md) 为准。

v11 smoke 第三项实际保存成功到版本1，随后模型又 recall 并 remember 相同内容到版本2，新进程确实读到版本2。原任务要求一次保存/版本1，按原规则失败并停止，不能把额外成功写入或如实回答版本2改算通过。此前也有精确键空读取成功后重复读取，耗尽单试验8请求的失败。

v12只补应用级结束说明：读任务一次recall成功（含空）后立即最终回答；写任务remember/forget成功后立即最终回答，不再验证读取或重复写入。工具后自动注入的记录是已提交结果，不是新的用户保存要求；实际写入冲突仍可按原CAS规则查询版本。保留实际工具事实/最终schema，不由宿主替模型补答。

模型/Pro/high/8192、语料、oracle、预期版本、8请求/16工具、局部限额与全局费用保护和全部门槛不变。新调用前提交指纹并登记，原585次/6.94020020元费用和所有失败保留，新完整7+81。新增第二次成功写入后真实较高版本仍须失败的评分反例。

替代是放宽版本期望、修改Memory幂等语义或不再检查实际mutation次数，均会改变本任务/SDK契约，不采用。代价是又一次观察失败后的提示选择，不能称盲测或保证模型必然服从；后续仍由真实固定任务与原门槛验收。
