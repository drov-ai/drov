# ADR-0016：受控文件、持久产物与可选 E2B 后端

日期：2026-10-14（Asia/Shanghai）。状态：用户已采纳范围建议；本决定用于实施，**文件/产物沙箱和 E2B 均尚未实现或验收**。补充并部分替代 [ADR-0013](0013-first-release-code-sandbox.md) 中 code-only、文件导入导出不纳入首版及云后端全部后续的范围；该决定的权限、单次派发、隔离与清理义务继续有效。

## 原因

只接收代码、返回文本足以验证小型计算，但缺少标准数据进出通道，无法完整交付 CSV 分析、图表和文件结果。Drov 的通用框架目标需要这些能力。AgentScope Python v2.0.9 的 workspace 与 E2B 官方机制核对见 [E-29 至 E-33](../planning/evidence.md) 和 [范围审查](../validation/sandbox-scope-review.md)，属于文档/固定源码事实，没有竞品性能或 Drov 云后端实验。

## 决定

1. C-17 首版必交增加受控文件输入与持久产物输出，纳入 T-10A/T-10B：宿主提交有界数据或显式授权已有 ArtifactRef，代码读取本次获准的输入，声明要导出的相对文件，得到不可变、有 hash 的持久产物引用。文件内容不塞入工具 JSON/上下文；原文件和主机目录不挂载。跨调用使用文件须显式再次授予引用，不保留容器、变量或隐式共享文件系统。
2. Docker 保持默认和必交后端。PythonSandbox 负责统一工具、权限/审批与结果契约，后端负责能力预检、资源身份、运行、文件传输、查证及销毁；公共参数不暴露 Docker 控制面。必要内部协议在真实 Docker 实施时建立，不预建 E2B 空壳。不同后端必须明确实际保证，缺少选定安全配置的能力接收前拒绝，不能把云 VM 描述为执行了 Docker seccomp/PID/tmpfs 配置。
3. 一次性标准库执行与固定数据分析镜像均纳入 Docker 验收；至少有 CSV 输入 → Python 分析 → CSV/PNG 输出 → 销毁容器后授权下载的案例。分析库由宿主在执行前构建/安装并固定镜像，运行中不安装。实际库版本、许可与 digest 在 T-10A 确定，不伪造当前准备镜像已含这些库。
4. 增加 T-10C，依赖 T-10B，作为首期系列的**可选、实验性 E2B adapter/extra**。与 T-11 等后续集成互不设前置，不阻塞 Docker v0.1 的必交链。第一版仅交付相同的单次 Python/受控文件/有界结果；显式禁止代码外连与公共服务访问，查询并销毁远端资源，不用 pause 代替清理。不增加 Shell 工具、持久 Notebook、联网安装、仓库/浏览器环境或多语言。
5. E2B 实施先完成不需要账号的适配与契约子范围；真实创建、传输、执行、费用与丢应答/取消/重启清理验收需要用户提供账号权限、可固定模板/构建、凭据引用、合成数据上传许可及独立沙箱预算。没有这些资源则保留未验收子范围，不能关闭 T-10C 或发布“已支持 E2B”的声明。若公开交付该 extra，其实际远端/安装/许可验收必须完成；可以从 Docker 版本构件中排除未完成的 adapter。
6. Artifact 元数据/Run 授权及结果属于事务存储，文件字节由显式私有本地 ArtifactStore 保存；文件落盘与 SQLite 不是一个原子事务。先保存有界、校验过的字节及私有暂存清单，确认执行已停止/销毁，再共同提交 ready 引用与工具结果。任何缺失、超限、提交失败或清理不明不能变成可下载的成功产物；恢复只查原执行/暂存证据，不重新计算。新增 B-18 覆盖这一边界，HTTP/UI/备份/清理复用同一授权与数据。

## 替代方案与代价

- 保留纯文本执行：实现更小，但文件/图表任务需要用户自建通道，不能满足本次确认的范围。
- 把 E2B 设为首版必交：增加账号、费用、云数据与远端不确定性，并使本地版本依赖外部资源；本轮选择独立可选任务。
- 同时提供持久交互工作区或任意主机挂载：增加共享状态、撤权、恢复和隔离责任；仍留后续。

文件能力增加私有存储、容量、路径/链接校验、权限和备份一致性成本；不会恢复被销毁的 Python 进程。云 adapter 增加可选依赖与费用/数据边界；供应商资源 ID、metadata 和 kill 不等于创建幂等或停止已确认。Docker 与 E2B 的能力差异需按真实版本验证，不能承诺完全等价或抵抗所有内核漏洞。

## 影响与实施

同轮同步能力表、API、运行/架构/工程、原三个代码变体与 X-03、质量、任务、维护发布、导航/开发/交接及 progress。源职责仍按规划导航分工；本 ADR 不复制数值默认、公共字段或测试矩阵。质量计划强化既有三个代码任务，不改变正式试验数量；E2B 远端契约验收与模型评分、模型预算分别记账。

P4 历史 fingerprint、已验收 T-01 至 T-10 与品牌保持不变；不重新开启一般规划。本轮只调整 Markdown，当前 schema/DDL/依赖和源码均未新增接口。下一轮按 progress 实施 T-10A，完整交付后进入 T-10B；T-10C 缺资源时先做独立离线子范围，其他必交任务可继续。
